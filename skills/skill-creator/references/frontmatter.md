# SKILL.md 的头部与目录

写法同 Claude Code。言只认其中几项，其余留着无害。

## 头部

| 字段 | 言认不认 | 说明 |
|---|---|---|
| `name` | 认 | 缺了用文件夹名。至多 64 字，不含 `< > : " / \ \| ? *`，不以点开头、不以点或空格结尾。与文件夹名一致，设置里改名时目录才跟着改。 |
| `description` | 认 | 进系统提示里的技能目录，每份一行，模型只凭它决定何时翻。至多 1024 字，宜一两句：做什么，何时用，相近却不该用的可点一句。 |
| `disable-model-invocation: true` | 认 | 不进模型的目录，只在人从「＋」→「技能」点名时用。适合要接外部服务、有副作用或很少用的。 |
| `user-invocable: false` | 认 | 不列进「＋」，模型仍可自己翻。适合给模型的背景知识。 |
| `license`、`metadata` | 留着 | 设置里改名字、何时用时原样保留。 |
| `argument-hint`、正文里的 `$ARGUMENTS` | 不认 | 点名时人的话就在附件下面，不必占位。 |
| `allowed-tools`、`model`、`context`、`hooks` 等 | 不认 | 工具与权限归言的设置（沙箱、问而后行），技能不能放宽。 |

## 目录

```text
name/
├─ SKILL.md      必有，唯一入口：模型先只看它
├─ references/   长参考：SKILL.md 写明何时翻哪一份
├─ scripts/      反复要跑的代码：写明怎么跑、要什么、出什么
└─ assets/       模板、样例、素材：拷去用，不当说明读
```

- **模型怎么取**：文本件以「技能名/路径」用 read_document 翻；脚本在有执事时照技能目录跑（SKILL.md 开头注着技能目录）。字体、图片这类模型读不了，只能交脚本用或拷给用户。
- **该不该拆**：不拆时模型每回都要读一大段用不上的，或同一段代码每回都要重写，才拆；否则留在 SKILL.md。拆出去的每件都要在 SKILL.md 里说明何时用，没被提到的件模型不知道去翻。
- **脚本用什么写**：言自带 Node，`.mjs` 零依赖到处能跑；Python、PowerShell 要用户机器上有，先查再用。脚本只做确定的事（解析、校验、转换），判断留给模型。
- **路径**：一律写相对技能目录的路径，不写本机的绝对路径。
- **大小**：言列一份技能至多 1000 件，单件翻阅至多 6 万字；更大的素材放夹里、由脚本处理。
