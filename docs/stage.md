# 游目

[← 文档目录](README.md)

模型借浏览器类的 MCP（如 playwright）上网、测它做的网页时，那个浏览器的画面收在言的右侧一栏，不再是屏幕上另开、挡人的一扇窗。游目上可点、可滚、可打字（输入法照常），标签与浏览器同步：模型新开一页或换到别的页，游目跟过去；点别的签，看那一页。

## 接法

浏览器仍由 MCP 起、关与操作，只多三个启动参数：开调试口 `9288`、放行言的页面、窗口挪到屏幕外。以 playwright 为例，写一份配置文件（如 `stage.json`）：

```json
{
  "browser": {
    "launchOptions": {
      "args": ["--remote-debugging-port=9288", "--remote-allow-origins=http://127.0.0.1:8787", "--window-position=-32000,-32000"]
    }
  }
}
```

在 设置 → MCP 里那个服务的 `args` 末尾添上 `--config` 与这份文件的路径；另添 `--allow-unrestricted-file-access`，模型才开得了本机的 `file://` 页，做出来的网页自己打开来看、改了再看，不必经人手：

```json
"浏览器": {
  "command": "node",
  "args": ["…/@playwright/mcp/cli.js", "--browser", "msedge", "--user-data-dir", "…/.edge-profile",
           "--config", "…/stage.json", "--allow-unrestricted-file-access"]
}
```

- 调试口言自己读：服务参数里的 `--cdp-endpoint`，或 `--config` 那份文件里 `launchOptions.args` 的 `--remote-debugging-port`；都没写的按 `9288` 去找。收藏所在的配置目录同样读参数里的 `--user-data-dir`（或文件里的 `userDataDir`）。改端口只改这份文件，不必动言。
- 调试口取 `9288` 而不取常见的 9222 / 9223：那两个常被远程调试的端口转发占着（`netsh interface portproxy`），占了 IPv4 的，浏览器只能退到 IPv6 上听，游目便找不到它。
- 任务栏上会多一枚 Edge：那就是这个浏览器，窗口在屏幕外，点它看不到东西，看它请到游目。
- 在服务的「给模型的话」里写一句「我说打开浏览器即指这个」，模型便不会去开系统默认的浏览器。
- 窗口挪到屏幕外而不用无头模式：无头的 Edge 在 UA 里带 `HeadlessChrome`，有的站点认得出来；屏幕外的窗口与平常无异，画面照出。
- `--remote-allow-origins` 只放行言的页面；别的网站连不上这个调试口。换了桥接端口（`YAN_PORT`）的，这里跟着改。
- 多个项目的网页（要构建的）照常起开发服务器，模型在浏览器里开 `localhost`。

## 用法

- 接了浏览器类的 MCP（工具里有 `browser_navigate` 的），正文右上角便自页顶垂下一笔朱竖；指针靠近，笔往下舒一点、笔尖下浮出「游目」两字，点它开游目。收起游目，这一笔回来。
- 浏览器没开、或被关掉了：游目里点「打开浏览器」，言替你调一次那个服务的 `browser_navigate`，浏览器照它的配置起来（登录状态、收藏都在）。
- 签条末的「＋」新开一页；地址栏右端一枚书签带小画是收藏，列出这个浏览器的收藏（按夹分层），点一条在当前页打开。
- 模型换到别的页（选签、新开），游目跟过去；你自己点了别的签，模型在原来那页上接着做时，游目不硬把你拽回去。
- 网页弹的提示框（alert、confirm、prompt、离页挽留）浏览器画在屏幕外的窗上，网页就此停住：游目在画面上另画一张，Enter 确定、Esc 取消。模型那头也收得到，谁先答都行。
- 载入中地址栏下一道朱线走着；后退、前进没处可去时淡下去。
- 浏览器的窗口跟着游目的大小走，网页原大显示；游目窄于 960×600 时窗口不再跟着缩（免得网站换成手机版），画面按比例缩小。
- 模型正在操作浏览器（调 `browser_*` 工具）时，那一笔朱竖的笔尖下一粒朱一明一暗，地址栏旁也一粒朱。
- 拖游目左缘调宽窄，宽度记在本机；「阔」铺满整页，Esc 退回。旁注也在右侧，旁注开着时游目暂让。
- 点画面即把键盘交给那一页：按键（含 Ctrl+C / V）、输入法打的字都递进去；点言的别处即收回。
- 地址栏可直接输网址、`localhost:端口`、本机路径（`E:\…\index.html`）；不像网址的（有空格、没有点）当成要搜的话，交给必应。

## 怎么做的

- 游目是那个浏览器的另一位看客：页面直连调试口，`Page.startScreencast` 收画面，`Input.*` 递点按，标签照 `Target.setDiscoverTargets` 抄。画面不过桥接；桥接只替页面问出连接的地址（`server/stage.js`，调试口的 `/json` 不给跨源读）。
- 网页的尺寸：playwright 有头时不设视口，网页多大即窗口多大。游目一变大小（停手 250 毫秒后），便以 `Browser.setWindowBounds` 把屏幕外那扇窗调成游目的大小，窗比网页多出的标签栏、地址栏按现量补上。设了固定视口的浏览器调窗口没用，画面照旧按宽高里较紧的一边缩放；点按都按同一倍数换算回去。
- 何时去连：开页时、打开游目时，与每次 `browser_*` 调用之后（浏览器多半是这时起的）。浏览器关了游目清空，不轮询。言自己从不起浏览器，「打开浏览器」也是经那个 MCP 服务起的。
- 跟页：每次 `browser_*` 调用之后顺带问一声浏览器前台是哪一页（调试口的 `/json/list` 按最近活动排，模型选签会把那页请到前台），与上回问到的不同才跟；你点签时游目也把那页请到前台并记下，所以不算模型换页。
- 浏览器自己画的那几样（提示框、载入中、能否后退）在屏幕外：游目对正看的那一页开 `Page.enable`，照 `javascriptDialogOpening`、`frameStartedLoading`、`frameNavigated` 等事件自己画；前后走 `Page.navigateToHistoryEntry`，不经网页里的脚本。
- 只在看得见时收画面：游目收起、被旁注挤开、言的页面到了后台，都停掉 screencast；回来再接上。
- 收藏：游目只转网页，浏览器自己的收藏栏在画面之外。收藏存在浏览器配置目录的 `Default/Bookmarks`，目录取自那个服务参数里的 `--user-data-dir`，由桥接读出（`POST /api/stage/bookmarks`，与找调试口一样只递那个服务的参数），每回现读。
- 网页改标题浏览器不发通知：游目开着时每一秒半问一次标签列表。
- 代码：`src/26-stage.js`、`styles/56-stage.css`；测试 `test/stage.mjs` 借测试用的 Edge 充当模型的浏览器。
